Политика конфиденциальности

Действует с 12 ноября 2026 г.

Коротко: игра не собирает и не передаёт персональные данные. В ней нет аккаунтов, мультиплеера, рекламы, аналитики и покупок внутри игры.

1. Что хранится на вашем устройстве

  • Настройки игры (громкость, яркость, качество графики, разрешение, язык, управление) и открытые достижения сохраняются в локальном хранилище браузера или приложения (localStorage) на вашем устройстве. Прогресс ночи не сохраняется.
  • Веб-версия и версия из Microsoft Store хранят копию файлов игры в кэше браузера (service worker), чтобы игра запускалась без интернета.
  • Эти данные не отправляются разработчику или третьим лицам. Чтобы удалить их, очистите данные сайта в браузере или удалите приложение.

2. Чего игра не делает

  • не требует регистрации и не запрашивает имя, адрес почты, телефон или другие контакты;
  • не использует файлы cookie, рекламные и аналитические сервисы;
  • не определяет местоположение и не использует камеру и микрофон;
  • голос рации синтезируется встроенными средствами вашего устройства, текст никуда не отправляется.

3. Сторонние сервисы

  • Хостинг. Файлы веб-версии загружаются с GitHub Pages (GitHub, Inc.). При загрузке страниц GitHub может обрабатывать технические данные, например IP-адрес, в журналах сервера — см. Положение о конфиденциальности GitHub.
  • Microsoft Store. Покупку, установку и обновления приложения из Microsoft Store обрабатывает Microsoft по Заявлению Microsoft о конфиденциальности. Разработчик получает от Microsoft только обобщённую статистику, например число установок, без сведений о конкретных людях.
  • Steam. В версии для Steam открытые достижения передаются в ваш профиль Steam через Steamworks (Valve Corporation) по Политике конфиденциальности Valve.

4. Дети

Это хоррор-игра для взрослой аудитории, она не предназначена для детей. Игра не собирает данные ни детей, ни взрослых.

5. Изменения

Если политика изменится, новая версия будет опубликована на этой странице с новой датой.

Before Dawn: The Forest Remembers

Privacy Policy

Effective November 12, 2026

In short: the game does not collect or share personal data. It has no accounts, no multiplayer, no ads, no analytics and no in-game purchases.

1. What is stored on your device

  • Game settings (volume, brightness, graphics quality, resolution, language, controls) and unlocked achievements are saved in the browser's or app's local storage (localStorage) on your device. Progress within a night is not saved.
  • The web version and the Microsoft Store version keep a copy of the game files in the browser cache (service worker) so the game can start without an internet connection.
  • This data is never sent to the developer or to third parties. To remove it, clear the site data in your browser or uninstall the app.

2. What the game does not do

  • it does not require registration and never asks for your name, email address, phone number or other contact details;
  • it uses no cookies, advertising or analytics services;
  • it does not access your location, camera or microphone;
  • the radio voice is produced by your device's built-in speech synthesis; no text is sent anywhere.

3. Third-party services

  • Hosting. The files of the web version are served by GitHub Pages (GitHub, Inc.). When pages load, GitHub may process technical data such as your IP address in server logs — see the GitHub General Privacy Statement.
  • Microsoft Store. Purchases, installation and updates through the Microsoft Store are handled by Microsoft under the Microsoft Privacy Statement. The developer receives only aggregated statistics from Microsoft, such as the number of installs, with no information about individual people.
  • Steam. In the Steam edition, unlocked achievements are sent to your Steam profile through Steamworks (Valve Corporation) under the Valve Privacy Policy.

4. Children

This is a horror game for a mature audience and is not directed at children. The game collects no data from children or adults.

5. Changes

If this policy changes, the new version will be published on this page with a new date.
