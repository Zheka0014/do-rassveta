Источники ресурсов

Женщина в подвале v41

Анатомия и исходный скелет — Female base mesh; одежда, текстуры взрослой кожи, глаза, брови, ресницы, зубы и волосы — Jordan. Оба ресурса опубликованы Innerscene на основе MakeHuman под CC0. Для игры одежда и волосы подогнаны к анатомии, перенесены веса, поставлена поза с опорой на ладони и колени, добавлен непрозрачный тканевый слой. Поза запечена, геометрия упрощена, встроенные текстуры сжаты. Полные сведения: ATTRIBUTION.txt. В v41 удлинена рубашка, добавлены объёмные подгибы, цвет загрязнений, один морф дыхания и зацикленный клип.

Смотритель v36

Цельная модель Zombie Walk Test — OSCAR CREATIVO, CC BY 4.0. Сохранены авторские геометрия, UV, скиннинг, текстуры цвета и нормалей. Изменены масштаб и материалы. Анимации Idle / Walk / Run — Adobe Mixamo из примера Three.js Soldier; перенесены на скелет модели. Добавлены коррекция стоп по рельефу, направление взгляда и процедурный замах. Подробная атрибуция: ATTRIBUTION.txt.

Poly Haven — CC0

Модели и текстуры используются по лицензии CC0. Часть моделей упрощена для браузерного рендера.

Модели:

  • Fir Tree 01 — высокие хвойные деревья, три уровня детализации.
  • Pine Sapling Small — молодые деревья трёх форм, два уровня детализации с общими текстурами.
  • Pine Roots — корни.
  • Fern 02 — папоротники.
  • Rock Moss Set 01 — камни.
  • Dead Tree Trunk — упавшие стволы.
  • Wooden Military Crate — ящики.
  • Wooden Lantern 01 — фонари.
  • Stone Fire Pit — каменное кольцо костра.
  • Tree Stump 02 — пни.
  • Grass Medium 01 — трава.

Материалы:

  • Forrest Ground 01 — лесная подстилка.
  • Weathered Planks — старая древесина; изба использует карты цвета, нормалей и шероховатости 2К.
  • Grey Roof 01 — кровля; карты цвета, нормалей и шероховатости 2К.
  • Материалы коры и хвои из наборов хвойных деревьев Poly Haven. Брёвна избы используют карты цвета, нормалей и ARM коры 2К из Fir Tree 01.

Three.js

Three.js 0.180.0 и GLTFLoader/BufferGeometryUtils — MIT. Текст лицензии: dist/vendor/THREE-LICENSE.txt.

Созданные ресурсы

Титульный лес и текстура пламени фальшфейера созданы встроенным ImageGen. Текстура пламени: dist/assets/flame.png; точный запрос сохранён в asset-prompts/flame.txt. Геометрия избы, объёмное пламя костра, модель руки с фонарём, тканевая поверхность перчатки, эффекты дождя, процедурное небо, облака и луна, постобработка, логика игры и процедурный звук созданы для этого проекта.

Кладбище, ограда, надгробия, гроб, повешенные фигуры, анимации, скрип верёвок, шёпот и колокол созданы для проекта. Каменные и деревянные поверхности переиспользуют указанные выше материалы Poly Haven.

Каталка, рация, костяные подвески, ткань с пятнами и их звуки также процедурно созданы для проекта.

Подвал, лестница и люк, двойник, сидящие фигуры, капканы, растяжки, дополнительные могилы и следы созданы для проекта; материалы переиспользуют приведённые выше источники. Для рации используются процедурный радиошум, текстовые реплики и локальный голос Web Speech API на языке игры, если он установлен. Пространственные шаги и звуки двери синтезируются Web Audio API.

Версия для ПК и Steam (v48)

  • Оболочка для ПК — Electron 44, MIT; лицензии Chromium поставляются рядом с исполняемым файлом (LICENSES.chromium.html).
  • Связь со Steam — steamworks.js 0.4, MIT. Включает распространяемые библиотеки Steamworks API от Valve (steam_api64.dll, libsteam_api.so, libsteam_api.dylib) по соглашению Steamworks SDK.
  • Значок игры, иконки 18 достижений и вёрстка капсул магазина созданы для проекта. В капсулах использован титульный лес (см. «Созданные ресурсы») и шрифты Playfair Display и PT Sans Narrow под SIL Open Font License 1.1; шрифты используются только в картинках и в игру не входят.
  • Скриншоты для магазина — кадры самой игры.
